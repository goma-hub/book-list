# 読書記録アプリ 概要

## プロジェクト概要

このプロジェクトは、ユーザーが読了した本を記録・管理するための読書記録アプリです。

ユーザーはメールアドレスとパスワードで認証し、自分の読書記録として本のタイトル、作者名、読了日、本の写真を登録できます。登録内容に不明な項目がある場合でも記録できるようにし、読書履歴を気軽に残せることを重視します。

## 目的

- 読み終えた本を一覧で振り返れるようにする
- 本の情報が一部不明でも、まず記録できるようにする
- ユーザーごとに読書記録を分けて管理する

## 主な機能

### ユーザー認証

- ユーザー登録
- ログイン
- ログアウト
- ログイン済みユーザーのみ自分の読書記録を閲覧・登録できる

### 読書記録の登録

登録できる情報は以下の通りです。

- 本のタイトル
- 作者名
- 読了日
- 本の写真
- あらすじや感想記載のためのメモ書き

各項目は不明な場合があるため、未入力でも登録できる設計にします。

### 読書記録の管理

- 登録した本の一覧表示
- 読書記録の詳細表示
- 読書記録の編集
- 読書記録の削除

## 初期開発スコープ

初期開発では、以下を優先します。

- ユーザー登録・ログイン・ログアウト
- 読書記録の作成・一覧表示・詳細表示・編集・削除
- ユーザーごとの読書記録の管理

## 将来的な拡張案

- タグやジャンル管理
