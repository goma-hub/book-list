# 読書記録アプリ システム要件

## 前提条件

このアプリは Cloudflare の無料プランを前提として開発します。

主な実行環境は Cloudflare Workers とし、データベースには Cloudflare D1 を使用します。ユーザー認証、読書記録 API、デプロイは Cloudflare Workers 上で扱います。

## 技術要件

### クラウド環境

- Cloudflare アカウントを使用する
- Cloudflare の無料プランで利用可能な範囲を基本とする
- Cloudflare Workers にアプリケーションをデプロイする
- Cloudflare D1 をデータベースとして使用する

### データベース

Cloudflare D1 に以下の情報を保存します。

- ユーザー情報
- パスワード認証に必要な情報
- 読書記録
- 本の写真の参照情報

画像本体は D1 に直接保存しません。画像をアップロードする場合は、Cloudflare R2 などのオブジェクトストレージに保存し、D1 には保存先のキーや URL を保存します。

### 認証

- メールアドレスとパスワードによる認証を行う
- パスワードは平文で保存しない
- パスワードはハッシュ化し、ソルトを使用する
- ログイン状態はセッション Cookie または署名付きトークンで管理する
- 認証が必要な API では、ログイン済みユーザーかどうかを確認する

### 読書記録

読書記録はログインユーザーに紐づけて管理します。

登録項目は以下です。

- 本のタイトル
- 作者名
- 読了日
- 本の写真

すべての項目は任意入力とし、不明な項目があっても登録できるようにします。

## 機能要件

### ユーザー機能

- ユーザー登録ができる
- ログインができる
- ログアウトができる
- ログイン済みユーザーのみ読書記録を操作できる
- 他ユーザーの読書記録は閲覧・編集・削除できない

### 読書記録機能

- 読書記録を登録できる
- 登録済みの読書記録を一覧表示できる
- 読書記録の詳細を表示できる
- 読書記録を編集できる
- 読書記録を削除できる
- 本の情報が一部未入力でも保存できる

## 非機能要件

### セキュリティ

- パスワードを平文で保存しない
- 認証が必要な API を未ログイン状態で実行できないようにする
- ユーザーごとのデータ分離を徹底する
- Cookie を使用する場合は `HttpOnly`、`Secure`、`SameSite` を適切に設定する
- 入力値を検証し、不正な値を保存しない

### 可用性・運用

- Cloudflare の無料プランの制限内で運用できる構成にする
- データベーススキーマをマイグレーションで管理できるようにする
- 環境変数やシークレットはコードに直接書かない
- 本番環境と開発環境を分けられる構成にする

### パフォーマンス

- 一覧表示では必要な項目のみ取得する
- 画像本体を D1 から配信しない
- 画像は必要に応じて圧縮・リサイズを検討する

## 想定データ構造

### users

| カラム名 | 内容 | 必須 |
| --- | --- | --- |
| id | ユーザー ID | 必須 |
| email | メールアドレス | 必須 |
| password_hash | ハッシュ化したパスワード | 必須 |
| created_at | 作成日時 | 必須 |
| updated_at | 更新日時 | 必須 |

### books

| カラム名 | 内容 | 必須 |
| --- | --- | --- |
| id | 読書記録 ID | 必須 |
| user_id | ユーザー ID | 必須 |
| title | 本のタイトル | 任意 |
| author | 作者名 | 任意 |
| finished_on | 読了日 | 任意 |
| photo_url | 本の写真の URL または保存先 | 任意 |
| created_at | 作成日時 | 必須 |
| updated_at | 更新日時 | 必須 |

## ローカル開発要件

- Node.js を使用する
- npm または互換パッケージマネージャーを使用する
- Cloudflare Workers の開発には Wrangler を使用する
- D1 のローカル開発環境または開発用 D1 データベースを使用する

## デプロイ要件

- Cloudflare Workers にデプロイできること
- D1 データベースとの接続設定ができること
- 本番用の環境変数とシークレットを設定できること
- GitHub への push は、明示的に指示された場合のみ実行する
